Troubleshooting

Problems encountered and their solutions

Problem

Conda (base) and .venv were active together.

Solution

Deactivate Conda first, then activate only the project's .venv. This keeps project packages separate and predictable.

Problem

ModuleNotFoundError: No module named 'app.classifier'

Solution

Add the missing classifier module and run Uvicorn from the correct backend directory.

Problem

The application reported that PostgreSQL was not connected.

Solution

Start the local PostgreSQL server and provide the correct DATABASE_URL in .env.

Problem

OpenAI enabled: False

Solution

Add OPENAI_API_KEY to the private .env file and restart the backend.

Problem

Email verification was not configured.

Solution

Production SMTP or an email API still needs to be configured. Until then, email registration cannot send verification codes.

Current problem

GitHub rejected the push because the saved token cannot update a workflow file.

Solution

Create a token with repo and workflow permissions, remove the old GitHub credential from macOS Keychain, and push the existing commit again.
